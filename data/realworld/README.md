# Optional real-world request traces

```text
data/realworld/BurstGPT_without_fails_1.csv
```

This dataset is not required for the Functional-badge smoke test and is not
redistributed by this source snapshot. Before claiming BurstGPT result
reproduction, document an authorized source, preprocessing steps, selected
request range, and SHA-256 checksum for the exact CSV used.
